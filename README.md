# Portfolio V0
> Primera versión de mi portafolio personal, desarrollado desde cero con HTML5 y CSS3, incorporando animaciones, diseño visual y una estructura preparada para futuras mejoras.
## Descripción
Portfolio V0 es la primera versión de mi portafolio web personal. El proyecto nace como un espacio para presentar mi perfil, proyectos, habilidades y evolución como desarrollador.

Esta versión está enfocada en construir una base sólida utilizando tecnologías web fundamentales, aplicando principios de diseño, organización del código y animaciones para crear una experiencia visual atractiva.
